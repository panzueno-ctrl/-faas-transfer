0. `sudo apt update && sudo apt upgrade -y && sudo apt autoremove -y && sudo apt autoclean`
   - À quoi ça sert : C'est une suite de commandes Linux pour mettre à jour le système WSL. Elle télécharge la liste des mises à jour (`update`), installe les mises à jour (`upgrade`), supprime les vieux paquets inutiles (`autoremove`), et nettoie le cache (`autoclean`).

============================================================
 HISTORIQUE DES COMMANDES UTILISÉES POUR LE PROJET
============================================================
Ce fichier répertorie les commandes système et git que j'utilise pour travailler sur votre projet, afin que vous puissiez apprendre à quoi elles servent.

1. `git add .`
   - À quoi ça sert : Ajoute TOUTES les modifications (nouveaux fichiers, fichiers modifiés ou supprimés) à l'index de Git. C'est l'étape de "préparation" avant de valider.

2. `git commit -m "mon message"`
   - À quoi ça sert : Valide (sauvegarde) les modifications préparées avec un message explicatif. C'est comme prendre une "photo" de l'état actuel de votre code.

3. `git push`
   - À quoi ça sert : Envoie les commits (sauvegardes) locaux vers le serveur distant (GitHub). Cela déclenche ensuite automatiquement Vercel et Render !

4. `npm install` (ex: `cd server && npm install`)
   - À quoi ça sert : Installe toutes les dépendances (les bibliothèques) listées dans le fichier `package.json` d'un projet Node.js.

5. `node index.js`
   - À quoi ça sert : Lance le serveur Node.js manuellement dans le terminal pour tester s'il démarre correctement sans erreur.

6. `curl -I https://votresite.com`
   - À quoi ça sert : Envoie une petite requête HTTP "ping" au serveur pour voir s'il répond bien. S'il répond 200, il est en ligne. S'il répond 404, la page n'existe pas.

7. `rm nomdufichier.js`
   - À quoi ça sert : Commande Linux/Mac (et WSL) pour supprimer définitivement un fichier. Par exemple, j'ai utilisé `rm test-upload.js` pour effacer le fichier de test.

8. `cp fichier1 fichier2`
   - À quoi ça sert : "Copy". Permet de copier/coller un fichier en ligne de commande. Je l'ai utilisé pour copier le logo SVG en favicon.ico.
